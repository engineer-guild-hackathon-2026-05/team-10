# 要求内容: 収益モデル・中長期ビジョンの追記

## 概要

プレゼン参照用に、HowTune の収益モデルと中長期ビジョンを PRD へ追記する。

## 背景

ハッカソン最終プレゼンの審査項目として「将来性・ビジネスモデル」が求められる。
アーティスト中心のプラスサム設計と、セレンディピティを軸とした人の繋がりを可視化したい。

## 追記する内容

### 1. 収益モデル（3本柱）

- **アーティスト向けインサイト（B2B）**: 身体反応ヒートマップをアーティスト・レーベルに提供するサブスク
- **チップ循環（P2P + アーティスト）**: リスナー間・リスナー→アーティストへのチップ。プラットフォームがマージンを取る
- **セレンディピティマッチング（Premium）**: 同曲・同瞬間に反応した見知らぬ人との出会いをプレミアム機能化

### 2. 中長期ロードマップ（フェーズ別）

| フェーズ | 機能 | 収益 |
|---|---|---|
| MVP（今） | How記録・共有 | 無料 |
| 6ヶ月 | アーティストダッシュボード | サブスク |
| 1年 | チップ機能 | マージン |
| 2年 | セレンディピティマッチング | プレミアム |

### 3. プラスサム設計の原則

- アーティストが金銭 + ファンインサイトを得る
- リスナーが認知 + 繋がり + 発見を得る
- プラットフォームは小さなマージンのみ取る
- ゼロサムにならない設計（チップ送信者も「発見者」として可視化）
