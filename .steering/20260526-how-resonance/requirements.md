# 要件定義: How Resonance（リアルタイム共鳴マッチング）

## 背景・目的

ハッカソン本番（2026-05-26）に向けたコア体験の完成。AirPods 装着者の「一番動いた瞬間」を起点に、
AI で深掘りして Howカードを作り、**同じ瞬間に反応した他者とリアルタイムにつながる**体験を実装する。

評価軸への狙い:
- **創造性 / 実用性**: 「同じ曲」ではなく「同じ瞬間・同じ How」でつながる payoff をデモで見せる
- **技術的挑戦**: 頭部モーションのピーク抽出 + LLM 深掘り + Firestore リアルタイム同期 + DM
- **完成度**: 聴く→ピーク検出→問いかけ→深掘り→Howカード→マッチング→DM を1本で通す

## グリル確定方針（本タスク固有）

- **モーションは ML を回さない**。再生中の加速度（interactionIntensity）ピークのタイムスタンプを「一番動いた所」として記録する。
- **1回目の問いかけは決めうち**（固定文）。ピーク地点について「ここどうですか」と問う。スケール時に分類モデルへ寄せる前提。
- **2回目の深掘りは LLM**（既存 ChatAPIClient/HowChat）。より詳細に掘ってコメント＋Howカードを作る。
- **3人デモ**: 他2人は Firestore に seed、実機1台が**リアルタイム購読**で読む（本番で確実）。
- **既存を破壊しない**。新規追加中心、既存フローは温存。

## 機能要件

### FR-RES-01 ピークモーション検出
- 再生セッション中、AirPods サンプルの `interactionIntensity` 最大値とその `playbackTime` を保持する。
- 受け入れ条件: セッション停止後に `peakMoment(playbackTime, intensity)` が取得できる。サンプルが無ければ nil。

### FR-RES-02 1回目の問いかけ（決めうち）
- ピーク地点を起点に固定文で問いかける（例: 「M:SS あたりで一番動いていました。ここ、どうでしたか？」）。
- 受け入れ条件: ピーク地点の時刻表示と固定選択肢が出る。LLM を呼ばない。

### FR-RES-03 2回目の深掘り（LLM）→ コメント + Howカード
- 1回目の回答後、既存 LLM 経路で深掘り、Howカードのコメント素案を作る。
- 受け入れ条件: 既存 HowChat の2ターン目が LLM 応答（mock/実バックエンド両対応）で、Howカード作成に渡る。

### FR-RES-04 Howカード投稿 → 同地点マッチング
- Howカード投稿時、`song_start`/`song_end` を反応区間として保存（既存 Functions 経由）。
- 同じ `song_id` の Howカードを **Firestore リアルタイム購読**し、時刻が ±2.5 秒以内で重なるものを「同地点反応者（🔥）」、それ以外を「別地点反応者」として表示。
- 受け入れ条件: 投稿後、同地点/別地点の反応者リストがリアルタイムに反映される。seed した2人が現れる。

### FR-RES-05 共鳴演出（量子→摩擦→発火）
- 同地点マッチ出現時に、分子がふわっと現れ→摩擦で熱を帯び→発火（🔥）するアーティスティック演出。
- 受け入れ条件（本タスクでは確実版）: マッチ出現時に演出が再生され、🔥マークが付く。リッチ版はフラグで分離。

### FR-RES-06 リアルタイム DM
- 同地点反応者（🔥）とチャットできる。メッセージは Firestore に書き込み、**スナップショット購読でリアルタイム反映**。
- 受け入れ条件: 2者間の会話が `conversations/{id}/messages` に保存され、購読側に即時反映。書き込みは楽観的更新で体感遅延を抑える。

### FR-RES-07 通常画面への🔥反映
- 通常の Howカード/反応表示画面で、同地点反応者がいる箇所に🔥マークを表示し、そこから DM に入れる。
- 受け入れ条件: 🔥マークのタップで該当 DM が開く。

## 非機能要件

- **書き込み速度**: DM は楽観的 UI（送信即時にローカル反映）＋ Firestore へ非同期書き込み。バッチ不要の単発書き込みで最小レイテンシ。
- **セキュリティ**: マッチング購読は認証済みユーザーのみ。DM は会話参加者のみ read/write（Firestore rules）。
- **デザイン**: 通常画面は Apple ネイティブ調を踏襲。共鳴演出のみアーティスティック（Metal/Canvas）。
- **検証**: headless ではビルド（xcodebuild）通過まで保証。見た目・実機リアルタイムは実機で確認。

## スコープ外（意図的）
- 3台の実機ライブ同期（seed + 単機購読で代替）
- ピーク以外の高度なモーション分類（将来モデルへ）
- DM の既読・通知・グループチャット
