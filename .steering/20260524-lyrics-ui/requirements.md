# 要求内容

## 概要

歌詞表示画面を、アルバムアート上でも読みやすく、長い歌詞でも崩れない SwiftUI レイアウトに組み直す。

## 背景

現在の Home 画面は歌詞がアートワーク上に直接重なり、背景によって文字が埋もれる。さらに歌詞一覧の行が横にはみ出すため、ユーザーが反応地点の歌詞を確認しづらい。

## 実装対象の機能

### 1. アートワーク中心の再生画面
- SyncBeat の再生 UI を参考に、円形アートワークと波形リングを主役にした画面へ再設計する。
- 未選択、読み込み中、取得不可の状態も同じ視覚トーンで表示する。

### 2. アートワーク下のスクロール歌詞
- 長い日本語/英語混在歌詞が画面幅内で折り返されるようにする。
- 現在行を視覚的に強調し、自動スクロールで追えるようにする。

### 3. 浮遊プレイヤー
- プレイヤー操作を `ZStack` の手前に固定表示する。
- 歌詞スクロール中も再生操作と進捗確認ができる。

### 4. Preview とビルド確認
- `#Preview` で実データに近い状態を確認できるようにする。
- Xcode ビルドで SwiftUI の型エラーがないことを確認する。

## 受け入れ条件

### アートワーク中心の再生画面
- [ ] アルバムアートが明るい/暗い場合でも歌詞が読める。
- [ ] 円形アートワークと波形リングで再生中の画面らしさが出る。
- [ ] 歌詞取得不可や未選択状態でレイアウトが崩れない。

### アートワーク下のスクロール歌詞
- [ ] 長い歌詞が横にはみ出さず、複数行で表示される。
- [ ] 現在行の背景・文字色・How 導線が判別できる。
- [ ] タップ領域が行全体にあり、How カード画面へ遷移できる。

### 浮遊プレイヤー
- [ ] プレイヤーが歌詞スクロールとは独立して手前に表示される。
- [ ] 曲名、アーティスト、再生状態、進捗が確認できる。

### Preview とビルド確認
- [ ] Home 画面の歌詞表示 Preview が追加されている。
- [ ] `xcodebuild` が成功する。

## 成功指標

- スクリーンショットで指摘された「文字が見えにくい」「下部歌詞が切れる」状態が解消される。
- 追加の外部依存なしで実装できる。

## スコープ外

以下はこのフェーズでは実装しません:

- 歌詞 API の取得精度改善
- MusicKit 再生制御の仕様変更
- 反応推論ロジックの変更
