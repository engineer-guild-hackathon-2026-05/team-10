# ADR-0006: HealthKit / 心拍連携をMVPから削除する

- **ステータス**: 採用済み
- **決定日**: 2026-05-25
- **決定者**: Team 10

## 背景

当初は AirPods 頭部モーションに加えて HealthKit 経由の心拍を補助シグナルとして扱う予定だった。しかし、ハッカソン MVP では以下の理由で実装・デモの安定性を優先する。

- 第三者アプリからのリアルタイム心拍取得は availability と粒度が不確実。
- HealthKit 権限要求はオンボーディングの摩擦が大きい。
- 現行体験は AirPods 頭部モーションだけで「身体が反応した曲中区間」を示せる。
- プライバシー説明とデータ管理の負荷を下げられる。

## 決定

MVP から HealthKit / 心拍 / HRV 連携を削除する。

- ヘルス権限を要求しない。
- 心拍データを取得しない。
- Firestore に心拍データを保存しない。
- 反応検出は AirPods 頭部モーション特徴量を主シグナルとする。
- `heartRateTrend` のような legacy 表示フィールドが残る場合も、実測心拍に基づくものとして扱わない。

## 結果

- 実機デモの成功率が上がる。
- プライバシー説明が簡潔になる。
- 「生理反応」よりも「頭部モーションによる身体反応」に訴求を寄せる。
- 将来 HealthKit を復活させる場合は、新しい ADR と明示的な権限・保存方針を作る。
