# ADR-0004: 「画面を見ない音楽体験」を主軸とする

- **ステータス**: 採用済み
- **決定日**: 2026-05-25
- **決定者**: Team 10（grill による設計審問で確定）

## 背景

Day3 提出に向け、HowTune の差別化軸（勝ち筋）をどこに置くかを再検討した。
既存の音楽アプリ（Spotify / Apple Music 等）は画面を見て操作することが前提で、曲・歌詞・ジャケットを画面で見る体験が中心である。

## 検討した選択肢

| 選択肢 | メリット | デメリット |
|---|---|---|
| **画面を見ない音楽体験** | AirPods センサーの必然性が際立つ。「見てないのに反応していた」というデモのギャップが強い。既存アプリと明確に差別化 | 聴取中の UI が作りにくく、事後体験に寄る |
| 身体反応の可視化（画面ありき） | Howカード・タイムラインが主役で作りやすい | 技術的だが地味。審査員へのインパクトが弱い |
| 同じ How でつながるコミュニティ | つながりが主役 | MVP ではマッチングがダミーで弱い |

## 決定

**「画面を見ない音楽体験」を主軸**とする。

- 聴いている間は画面を見ない。AirPods の頭部モーションが裏で身体反応を記録する
- 聴き終わってから画面で振り返り・AI 対話・つながる（二段構成）

## 結果

- AirPods センサー（ADR-0001 でネイティブ iOS を選んだ根拠）の必然性が、プロダクトの核として際立つ
- デモのクライマックスが「**見ていないのに、身体は正直に反応していた**」というギャップになる
- 既存の画面操作前提の音楽アプリと明確に差別化できる
- 関連: 主シグナルは頭部モーション（ADR-0005）。デモゴールは「聴く → 可視化 → AI 対話 → How カード」
